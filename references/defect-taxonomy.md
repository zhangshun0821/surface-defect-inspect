# 缺陷判定准则

判读前必读。本文件定义两类目标细节的边界、常见混淆与严重度分级。

## 一、线状痕迹 `scratch`

**定义**：表面出现的**细长、连续、方向性**的痕迹。共同特征是"长宽比大"、
"沿某一条路径延伸"，与产品本身的结构无关。

| 子类 subtype | 形态描述 | 典型成因 |
| --- | --- | --- |
| `scratch` | 单一细线，边界较锐利，长度通常 > 2 倍宽度 | 硬物刮擦、装配摩擦 |
| `abrasion` | 密集细线成片，方向一致，呈"拉丝/雾面"状 | 擦拭、磨蚀、喷砂不均 |
| `scuff` | 宽而浅的擦痕斑块，边界弥散，内部有细纹 | 拖拽摩擦、袋内磨损 |
| `crack` | 线状但伴随边缘翘起/分叉/贯穿 | 应力开裂 |

**判定要点**
* 长宽比 ≳ 3 的孤立线状结构。
* 边缘可以锐利也可以弥散——**弥散不等于不是划痕**（`scuff`/`abrasion` 常见）。
* 划痕终点通常逐渐变淡，而非齐平切断。
* 一片密集的平行细线（`abrasion`）应当作为**一条**缺陷记录，不要逐条记录。

## 二、局部缺损 `chip`

**定义**：表面**局部的材料缺失或破损**，呈块状/点状/缺口状。与划痕的区别是
"占面积"而非"占长度"。

| 子类 subtype | 形态描述 | 典型成因 |
| --- | --- | --- |
| `pit` | 孤立的小凹坑/点状暗斑，边界柔和，内部偏暗 | 腐蚀、气孔、压痕 |
| `chip` | 边缘锐利的碎块缺失，缺口处颜色/质感与母材不同 | 磕碰、崩边 |
| `missing_material` | 成片区域露出底层/背景/不同颜色 | 涂层脱落、贴纸剥离 |
| `hole` | 轮廓闭合的贯穿孔，孔壁可见 | 钻孔缺陷、虫蛀 |

**判定要点**
* 轮廓应大致闭合且**短轴 ≥ 3 倍**长轴以内（长宽比 ≲ 3）。
* 缺损处通常与母材**质感/颜色不同**（更亮=露出底材，更暗=凹陷阴影）。
* 位于**轮廓边缘**的缺口（缺了一块）与**内部**的坑要分开记：`region` 写清楚。
* 表面正常的孔（螺丝孔、按键间隙、散热孔、装饰孔）是**产品结构**，不是缺陷。
  只有当孔的边缘出现破损/不规则形变时才计为 `chip`。

### 材料缺失 vs 材料交界（最容易漏判的一类）

多材质零件（蓝色塑料柱 + 白色泡沫套管之类）的交界处，既可能是**设计好的成型结构开口**，
也可能是**涂层/包覆缺失导致的暴露底材**。两者形态相似，必须分开：

| | 设计结构开口 | 材料缺失（`missing_material`） |
| --- | --- | --- |
| 边界 | 平顺、连续、沿轮廓走 | 锯齿状、不规则、有豁口 |
| 内部 | 颜色单一，是另一种材料的正常表面 | 颜色与两侧都不同，或有明显的破损纹理 |
| 对称性 | 整个周向对称一致 | 只在局部出现，同一零件其它视角不对应 |
| 走向 | 与几何轮廓平行 | 侵入母材内部，边界不平行于任何结构线 |

**判据**：看同一材料交界在**其它视角**是否呈现同样的规整形态——结构开口每个视角都规整；
局部豁口只出现在部分视角。存疑时按 `missing_material` 低置信度记录，**不要因为"像是结构"而略过**。

## 三、两类混淆对照

| 现象 | 判为 | 理由 |
| --- | --- | --- |
| 细长、高长宽比 | `scratch` | 长度主导 |
| 短粗、近圆形/方形 | `chip` | 面积主导 |
| 细线交汇成网、边界弥散 | `scratch` / `abrasion` | 仍以线状单元构成 |
| 团块但内部可见平行细纹 | `scratch` / `scuff` | 以线状单元构成 |
| 边界锐利、内部均匀、无纹理 | `chip` | 材料缺失 |
| 沿物体**轮廓**的一条细亮线 | 通常**不是**划痕 | 是边缘高光/轮廓线 |
| 规则重复的条纹（拉丝纹、滚花） | **不是**划痕 | 是表面工艺纹理 |
| 阴影/渐变边界 | **不是**缺陷 | 是形体与光照造成的明暗过渡 |

## 四、不是缺陷的东西（务必排除）

* 产品的**设计结构**：孔位、凹槽、倒角、分模线、接缝、铭文、logo、按键缝隙。
* **光照伪影**：镜面高光、反射边界、阴影边缘、色偏。这些随视角变化而变化。
* **渲染噪声**：图像本身的颗粒感。
* 拍摄瑕疵：压缩噪点、反光白斑。

**跨视角判据（最强的一条）**：同一物理缺陷在所有视角下都出现在**同一个表面部位**；
而光照伪影和轮廓高光会随视角明显移动或消失。若某条痕迹在 3 个以上视角都能在同一部位
对上，它就是缺陷。

## 五、严重度 `severity`

| 值 | 判定 |
| --- | --- |
| `minor` | 长度短 / 面积小 / 对比度低，不影响外观判定，需要近看才能发现 |
| `moderate` | 明显可见的痕迹或缺损，正常光照下可察觉 |
| `severe` | 醒目、贯穿/大面积、或位于产品最显眼的主可视面上 |

严重度**独立于置信度**：
* `confidence` = 你有多确定它是缺陷（会不会是反光/结构）
* `severity` = 它有多严重

## 六、置信度 `confidence` 建议取值

| 区间 | 含义 |
| --- | --- |
| 0.9 – 1.0 | 多视角可互证，形态明确，无歧义 |
| 0.7 – 0.9 | 单视角但形态清晰、明显非结构 |
| 0.4 – 0.7 | 形态可疑，可能是反光或纹理；已如实记录 |
| < 0.4 | 几乎不可确认（一般仍应记录，但可在 `notes` 里说明） |

**宁可低置信度地报，也不要漏报**：漏报（false negative）在质检评价中的代价通常
高于误报（false positive）。把握不足时给 0.4–0.6 的置信度即可。
